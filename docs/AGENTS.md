# Reglas para documentación

- Mantenga los procedimientos ejecutables y verificables.
- Indique precondiciones, comandos, resultados esperados y rollback cuando proceda.
- No documente secretos reales ni pegue salidas con credenciales.
- Diferencie hechos verificados, decisiones y propuestas.
- Si cambia comportamiento, actualice la documentación en el mismo cambio.
