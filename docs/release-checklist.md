# Checklist de release

1. Confirmar criterios de aceptación y estado limpio del repositorio.
2. Ejecutar `scripts/check.*` y `scripts/security.*`.
3. Revisar dependencias, permisos y avisos de seguridad.
4. Actualizar `CHANGELOG.md` y `VERSION`.
5. Generar checksums con `scripts/checksums.*` cuando se distribuyan artefactos.
6. Documentar rollback.
7. Crear tag/release solo tras aprobación humana.
