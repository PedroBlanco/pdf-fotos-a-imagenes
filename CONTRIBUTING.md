# Contribución

1. Cree una rama o worktree por cambio.
2. Mantenga el alcance pequeño y referencie la issue.
3. Ejecute `scripts/check.*` y `scripts/security.*`.
4. Abra una PR con pruebas, riesgos y documentación.
5. No incluya secretos ni datos sensibles.

Consulte `AGENTS.md` para las reglas que también debe seguir Codex.
